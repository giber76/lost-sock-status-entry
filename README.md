## The line (116 characters)

> Update: I live in a raincoat pocket. Rent's free, the view is lint, and my partner already replaced me with a glove.

## Why this line

- **A real status update from a lost sock:** it opens with "Update:", it is a small domestic sock's weary voice, and the sock is somewhere it should not be — a raincoat pocket.
- **The laugh lands in the last few words:** three beats (the new home, the rent/view joke, the partner) build to the punchline — the partner has already moved on, to a glove.
- **Twists the obvious material:** the missing-partner trope is turned somewhere unexpected (replaced by a glove, the hand's sock), and the dryer is dodged entirely rather than repeated.
- **Original:** written fresh for this bounty, no recycled joke or borrowed quote.

## How it runs

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt`. Run locally with:

